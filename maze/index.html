How width and cell size relate

Width is measured across the outer walls. Set the width and the cell size follows, or set the cell size and the width follows; whichever you set last is kept when the grid changes.

06 Export 2D
About SVG and DXF

SVG for printing, plotting and laser cutting; it includes the solution and colouring only if they are shown. DXF for CAD (Inventor: Sketch › Insert AutoCAD file, units mm): layer WALLS has closed wall outlines ready to extrude, CENTERLINES the wall centre lines and SOLUTION the route.

07 Export 3D mm
About STEP and STL

STEP opens as a solid body in CAD (Inventor, Fusion, SolidWorks, FreeCAD). STL is a mesh for slicers. Both are watertight and in millimetres. With a ground plane (border above 0) the maze is one solid; without one, each connected run of walls is its own body.
